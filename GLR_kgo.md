## 4. Module Overview
The **kgo** hardware module is a 6U CompactPCI wideband RF receiver designed for military applications. It operates from 5 GHz to 18 GHz with high gain flatness and low noise figure.

**RF SECTION:**
The RF chain comprises a wideband LNA (HMC1099LP4DE), followed by a digital VGA (HMC698LP4) for gain control, and a high-linearity mixer (HMC1052LP4E) for downconversion. The local oscillator is generated by the ADF5356 synthesizer. The system handles input power from -60 dBm to -10 dBm.

**DIGITAL SECTION:**
The core logic is implemented in a Xilinx 7-Series Kintex FPGA (XC7K325T-FFG900). The FPGA manages the SPI configuration of the RF components (VGA, PLL, Mixer bias), controls the AGC loop, and monitors system health. It interfaces with the ADC via LVDS and communicates with the host via CompactPCI J1 (mapped to UART/Control).

**POWER SUPPLY SECTION:**
Power is derived from the CompactPCI backplane (+5V, +3.3V, +12V). DC-DC converters generate the required rails: +1.0V (FPGA Core), +1.8V (FPGA DDR/TR), +3.3V (FPGA IO), and specific rails for RF components (e.g., +5V LNA). Power sequencing is managed by a dedicated supervisor or FPGA logic to ensure correct startup.

## 5. Features
- **FPGA:** Xilinx XC7K325T-FFG900 (Kintex-7 Family)
- **On-board clock oscillator:** 125 MHz CMOS Oscillator (System Clock)
- **Communication:**
    - UART (via RS-422 Transceiver) at 115200 bps for Control Plane
    - SPI Master for RF Component Configuration
    - I2C Master for EEPROM/Sensors
- **JTAG debugging support:** Standard 14-pin header
- **EEPROM:** AT25640 (64Kb) for storing calibration data
- **Configuration Flash:** MT25QL128 (128Mb) for FPGA bitstream storage
- **Temperature Monitoring:** AD7416 (I2C) for PCB and FPGA die temp
- **Power monitoring:** LTC2992 (I2C) for voltage/current rail monitoring
- **RF Control:** 6-bit Parallel control for VGA, SPI for PLL (ADF5356), MUX control for Mixer
- **ADC Interface:** 12-bit LVDS Data bus (12 pairs + Frame/Clock)

## 9. Functional Specifications

**Summary table first:**

| S.No. | Function Name | Description |
|:---:|:---|:---|
| 1 | Serial Communication Interface | UART between Host & FPGA via cPCI J1 mapped to RS-422 |
| 2 | High Speed Data Interface | 12-bit LVDS bus receiving data from RFADC-12X1000 at 1 GSPS |
| 3 | Power Supply Sequencing & Health Status | Monitors +3.3V, +5V, +12V rails; enables RF Power Amplifiers/LNA only when stable |
| 4 | Supply Voltage, Current & Temperature Monitoring | I2C based polling of LTC2992 (Power) and AD7416 (Temp) |
| 5 | Flash Interfaces | QSPI Configuration Flash (MT25QL128) for FPGA bitstream and SPI EEPROM for params |
| 6 | VGA / AGC Configuration | 6-bit Parallel bus to HMC698LP4 for gain adjustment based on ADC power |
| 7 | FPGA Remote Programming | Configuration loading via UART SelectMAP protocol |
| 8 | PLL Synthesizer Controlling | SPI interface to ADF5356 for LO generation (Downconversion) |
| 9 | Data Capture & Buffering | DDR buffering and formatting of LVDS ADC data for backplane transport |

Then provide DETAILED subsections:

### 9.1 Serial Communication Interface
- **Interface type:** UART
- **Physical layer:** RS-422 (Differential) via ADM3308E transceiver
- **Baud rate:** 115200 bps (Fixed)
- **Frame format:** 1 start bit, 8 data bits, 1 stop bit, no parity (8N1)
- **USB-UART converter IC:** N/A (Integrated onto cPCI backplane or carrier card)
- **Signals:** UART_TX (FPGA → Host), UART_RX (Host → FPGA)
- **Protocol:** Custom register-based command/response (defined in Section 11)

### 9.2 High Speed Communication Interface
- **Interface:** Source Synchronous LVDS
- **Number of lanes:** 12 Data lanes (D11:0) + 1 Clock lane + 1 Frame lane
- **Data rate:** 1000 Mbps per lane (1 GSPS DDR equivalent)
- **Protocol:** Custom data framing compliant with JESD204B or proprietary alignment (dependent on ADC config)
- **Physical:** Direct connection to RFADC-12X1000 output pins; Internal termination to 100 Ohm differential.

### 9.3 Power On/Off Sequence
#### 9.3.1 Power ON/OFF Sequence
1. Input supply (+5V, +3.3V, +12V) detected within limits -> `POR_N` asserted by supervisor.
2. FPGA Core voltage (1.0V) ramps up.
3. FPGA releases `INIT_N` and loads configuration from Flash.
4. FPGA asserts `FPGA_DONE`.
5. FPGA enables LNA (`LNA_ENABLE` = HIGH).
6. FPGA enables PLL (`PLL_CS_N` logic high).
7. System Ready flag set in `SYS_STATUS` register.

#### 9.3.2 Mode Configuration
| Mode | Signal | Value | Description |
|:---|:---|:---:|:---|
| Normal | MODE[1:0] | 2'b00 | Standard RX operation |
| Test | MODE[1:0] | 2'b01 | Built-in self-test (PRBS generation) |
| Programming | MODE[1:0] | 2'b10 | FPGA remote update mode |

### 9.4 Supply Voltage, Current & Temperature Monitoring
#### 9.4.1 Supply Voltage and Current Monitoring
- **IC Part Number:** LTC2992
- **Interface:** I2C at Address 0x6C
- **Monitored rails:** +3.3V, +5V, +12V, +1.0V (FPGA Core)
- **Measurement range:** 0 to 20V, 0 to 10A (via sense resistors)
- **Resolution:** 16-bit ADC

#### 9.4.2 Temperature Monitoring
- **IC Part Number:** AD7416
- **Interface:** I2C at Address 0x48
- **Temperature range:** -55°C to +125°C
- **Resolution:** 0.25°C (10-bit ADC)
- **Alert threshold:** > 110°C (Critical), > 90°C (Warning)

### 9.5 Flash & Interfaces
#### 9.5.1 Configuration Flash
- **Part Number:** MT25QL128
- **Interface:** QSPI (Quad SPI)
- **Capacity:** 128 Mb
- **Purpose:** Stores FPGA programming bitstream
- **Programming:** Via UART Remote Programming or JTAG

#### 9.5.2 Storage Flash (User Flash)
- **Part Number:** Uses same MT25QL128 (High address space) or separate partition
- **Interface:** QSPI
- **Capacity:** Reserved 16 Mb
- **Purpose:** Stores Gain Calibration Tables, Frequency Response Correction Tables

### 9.6 RF Gain Control (AGC)
- **Signal:** `VGA_GAIN[5:0]`
- **Direction:** FPGA → HMC698LP4
- **Logic level:** 3.3V LVTTL
- **Step size:** 1 dB per code (Total range -11.5 to +20 dB)
- **Control:** Automatic (Firmware loop reading ADC RMS power) or Manual (Host Register write)

### 9.7 FPGA Remote Programming
- **Protocol:** UART at 115200 bps
- **Tool:** Python-based GUI or Host Application
- **Procedure:**
  1. Host sends 0x55 0xAA magic sync sequence.
  2. FPGA enters programming mode.
  3. Bitstream transferred via XMODEM or custom protocol.
  4. FPGA writes to Configuration Flash via SPI Master.
  5. FPGA triggers IPROG command to reload.

### 9.8 Phase Shifter / PLL Control
- **Control basis:** Desired LO Frequency
- **Interface:** SPI (CLK, MOSI, MISO, CS_N)
- **PLL Part:** ADF5356
- **Frequency Range:** 53.125 MHz to 13.6 GHz
- **Register Map:** 28 registers (34-bit shift register structure)

### 9.9 Beam Steering Calculation
- **Algorithm:** N/A (Not applicable for single channel receiver kgo)

### 9.10 Gate Voltage Writing in DAC
- **DAC Part:** N/A (Analog VGA used, no Gate DAC required).

## 11. UART Register Protocol Specification

This section provides the EXACT byte-level frame format for the UART register protocol. Firmware MUST implement this exactly.

### 11.1 Physical Layer
- Baud rate: 115200 bps
- Frame format: 1 start bit, 8 data bits, 1 stop bit, no parity (8N1)
- Physical interface: RS-422
- Signal levels: 3.3V logic (differential)

### 11.2 Command Frame Formats

**Single Register Write (CMD = 0x57 'W'):**
```
Byte 0: 0x57 (CMD)
Byte 1: ADDR[15:8] (address MSB)
Byte 2: ADDR[7:0]  (address LSB)
Byte 3: DATA[15:8] (data MSB)
Byte 4: DATA[7:0]  (data LSB)
→ Response: 0x06 (ACK) within 1ms, or 0x15 (NAK) on error
Total frame: 5 bytes TX, 1 byte RX
```

**Single Register Read (CMD = 0x52 'R'):**
```
Byte 0: 0x52 (CMD)
Byte 1: (ADDR[15:8] | 0x80)  (MSB with read bit set)
Byte 2: ADDR[7:0]             (address LSB)
→ Response: DATA[15:8], DATA[7:0] within 2ms
Total frame: 3 bytes TX, 2 bytes RX
```

**Bulk Register Write (CMD = 0x42 'B'):**
```
Byte 0: 0x42 (CMD)
Byte 1: ADDR[15:8] (start address MSB)
Byte 2: ADDR[7:0]  (start address LSB)
Byte 3: N          (register count, 1–64)
Byte 4..4+2N-1: DATA[0]_H, DATA[0]_L, ..., DATA[N-1]_H, DATA[N-1]_L
→ Response: 0x06 (ACK) within 5ms, or 0x15 (NAK)
Total frame: (4 + 2N) bytes TX, 1 byte RX
```

**Bulk Register Read (CMD = 0x62 'b'):**
```
Byte 0: 0x62 (CMD)
Byte 1: (ADDR[15:8] | 0x80)  (MSB with read bit set)
Byte 2: ADDR[7:0]             (start address LSB)
Byte 3: N                     (register count, 1–64)
→ Response: DATA[0]_H, DATA[0]_L, ..., DATA[N-1]_H, DATA[N-1]_L within 5ms
Total frame: 4 bytes TX, 2N bytes RX
```

**Error Response:**
```
0x15 (NAK) — sent by FPGA when:
  - CMD byte not recognized
  - Address out of valid range
  - Write to read-only register
```

### 11.3 Protocol Timing Constraints
| Parameter | Min | Typical | Max | Unit |
|:---|:---:|:---:|:---:|:---|
| Inter-byte gap (TX side) | - | - | 50 | ms |
| Single Write response time | - | 0.5 | 1 | ms |
| Single Read response time | - | 1 | 2 | ms |
