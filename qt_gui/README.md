# kb — Qt C++ GUI Application

Generated by Hardware Pipeline v2

## Requirements

- **Qt 5.14.2** (QtSerialPort module required)
- **QMake** (bundled with Qt)
- **MinGW 32-bit or 64-bit** (Windows 10) — or MSVC 2017+

## Build (Qt Creator — recommended)

1. Open `qt_gui/kb.pro` in Qt Creator
2. Select a Qt 5.14.2 MinGW kit
3. Click **Build** (Ctrl+B)

## Build (command line)

```bat
cd qt_gui
qmake kb.pro
mingw32-make -j4
```

## Project Structure

All UI is defined in Qt Designer `.ui` files — no dynamic widget creation in C++.
Promoted widgets are used in `MainWindow.ui` for each sub-panel.

| File | Role |
|------|------|
| `MainWindow.ui` | QTabWidget with 4 promoted-widget tabs |
| `DashboardPanel.ui/.h/.cpp` | Live data table + stat cards |
| `ControlPanel.ui/.h/.cpp` | Manual command entry + history |
| `LogPanel.ui/.h/.cpp` | Colour-coded serial log |
| `SettingsPanel.ui/.h/.cpp` | Port / baud / parity configuration |
| `SerialWorker.h/.cpp` | QThread-based QSerialPort I/O |

## Features

- **Dashboard** — live data table (200-row ring), stat cards, progress bar
- **Control** — command entry + history list, Send on Enter or button
- **Log** — colour-coded (RX=teal, TX=blue, ERR=red, INF=amber)
- **Settings** — port/baud/data-bits/parity/stop-bits, Refresh Ports
- **SerialWorker** — QThread I/O, newline-framed packets, thread-safe invoke
- **Dark theme** — Fusion style + QPalette (#0f1423 navy, #00c6a7 teal)
