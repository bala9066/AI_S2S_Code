## 1. Scope of the Document
This document defines the Input/Output (I/O) details, timing constraints, and functional requirements of the Xilinx Zynq UltraScale+ FPGA (XCZU9EG-FFVB1156) for the **iguyc** Wideband RF Receiver project.

It serves as the bridge between the hardware schematic/netlist (P4) and the FPGA logic design (P7), detailing the electrical interfaces for the RF Front-End control (LNA, Mixer, VGA), Local Oscillator (LO) synthesis, and high-speed digitization (ADC) interfaces.

## 4. Module Overview

The **iguyc** module is a high-performance wideband RF receiver designed for military applications. It operates from 5 GHz to 18 GHz with a tunable instantaneous bandwidth of 1-2 GHz.

**RF SECTION:**
The RF chain consists of a wideband **LNA (HMC6987LP4E)** followed by a downconversion **Mixer (HMC1194LP4E)**. The LO is generated by an **ADF5355** synthesizer, multiplied by **HMC3716LP4** and amplified by **HMC679LP4**. IF gain control is managed by a digital **VGA (HMC698LP4)**.

**DIGITAL SECTION:**
The core is the **Xilinx XCZU9EG-FFVB1156** FPGA. It handles the JESD204B interface to the **ADC12DJ3200**, controls the RF gain state via SPI, configures the LO frequency, and manages power-up sequencing. It provides a processed output via high-speed transceivers or custom CMOS.

**POWER SUPPLY SECTION:**
Power is regulated via the **ADP5054** (for FPGA rails) and **LTM4644** (for RF and ADC rails). Critical rails include +5V_RF, +1.2V_ADC, and FPGA core voltages (+0.85V VCCINT, +1.8V VCCAUX).

## 5. Features
*   **FPGA:** Xilinx Zynq UltraScale+ XCZU9EG-FFVB1156 (Kintex UltraScale+ class logic).
*   **ADC:** Texas Instruments ADC12DJ3200 (12-bit, 3.2 GSPS dual-channel) with JESD204B interface.
*   **LO Synthesis:** Analog Devices ADF5355 microwave PLL with SPI control (up to 13.6 GHz).
*   **Gain Control:** Analog Devices HMC698LP4 Digital VGA with parallel interface.
*   **Power Management:** ADP5054 with I2C control for voltage monitoring and sequencing.
*   **Data Interface:** High-speed JESD204B (lanes) to FPGA SERDES blocks.
*   **Debug:** JTAG (14-pin header) for FPGA configuration and debug.
*   **Config:** Quad-SPI Flash support on FPGA for bitstream storage.

## 6. FPGA Description

**Selection Rationale:**
The Xilinx **XCZU9EG-FFVB1156** is selected to meet the high data throughput requirements of the 12-bit, 3.2 GSPS ADC. The integrated SERDES capable hard blocks are required to ingest the JESD204B data stream from the ADC12DJ3200 without consuming soft logic resources. Additionally, the high logic capacity allows for real-time DSP (FFT, filtering) and the PS (Processing System) ARM cores allow for complex control logic and communication handling.

*(Reference Schematic Diagram - See Project Documents)*

**Flow Description:**
RF Input (5-18GHz) → LNA → Mixer → IF Filter → VGA (HMC698LP4) → ADC (ADC12DJ3200).
FPGA controls:
1.  **Parallel Interface:** Sets HMC698LP4 Gain.
2.  **SPI Interface:** Configures ADF5355 LO frequency.
3.  **JESD204B:** Receives digitized IF data from ADC.
4.  **I2C Interface:** Monitors rails via ADP5054 and ADC status.

## 9. Functional Specifications

### Summary Table

| S.No. | Function Name | Description |
|:---:|:---|:---|
| 1 | **High-Speed Data Interface** | JESD204B interface to receive digitized IF data from ADC12DJ3200. |
| 2 | **Gain Control Interface** | Parallel digital interface to HMC698LP4 for AGC functionality. |
| 3 | **LO Synthesis Control** | SPI interface to configure ADF5355 frequency and multiply chain. |
| 4 | **Power Supply Monitoring** | I2C interface to ADP5054 for voltage/current monitoring and sequencing. |
| 5 | **System Configuration** | UART interface for command/control and configuration upload. |
| 6 | **JTAG Debug** | Standard IEEE 1149.1 boundary scan and debug access. |
| 7 | **Clocking** | Distribution of reference clocks and synchronization signals. |

### 9.1 High Speed Communication Interface (JESD204B)
*   **Function:** Transport of digitized IF samples from the ADC to the FPGA.
*   **Standard:** JESD204B Subclass 1 (deterministic latency).
*   **Lanes:** 6 Lanes (Lane 0-5) mapped to FPGA GTY transceivers.
*   **Data Rate:** 12.288 Gbps per lane (dependent on ADC encode rate).
*   **Scrambling:** Enabled (as per JESD204B standard).
*   **PLL:** GTY Transceiver PLLs locked to ADC DCO.
*   **Buffers:** Input Buffer (IBUFDS_GTE4) instantiation required.
*   **FPGA Core:** Uses Xilinx IP "JESD204B PHY" and "RX Subsystem".

### 9.2 VGA / Gain Control Interface
*   **Component:** HMC698LP4 (Variable Gain Amplifier).
*   **Interface Type:** Parallel Synchronous (3-bit data bus).
*   **Signals:**
    *   `VGA_CLK`: Generated by FPGA (Max 20 MHz).
    *   `VGA_LE`: Latch Enable (Active High pulse).
    *   `VGA_DATA[1:0]`: Gain setting data.
*   **Logic:**
    *   FPGA must toggle `VGA_CLK` and present data on `VGA_DATA` pins.
    *   Assert `VGA_LE` for at least 5ns to latch gain.
    *   Gain settings correspond to attenuation tables defined in FPGA memory.

### 9.3 Power On/Off Sequence
#### 9.3.1 Power ON Sequence
1.  **System Input:** +12V applied.
2.  **Sequencing:** ADP5054 enables +5V_RF and +1.8V rails. FPGA monitors `PWR_GOOD`.
3.  **FPGA Init:** FPGA VCCINT rises. `INIT_N` signal goes high.
4.  **Configuration:** FPGA loads bitstream from SPI Flash.
5.  **RF Enable:** Only after `FPGA_DONE` is asserted, the FPGA enables the +5V_RF to the LNA/Mixer via GPIO control of the LTM4644 enable pin (implied control).
6.  **ADC Calibration:** FPGA asserts `ADC_RESET_N` (if available) and initializes JESD204B link.
7.  **Ready:** `LED_STATUS` toggles to indicate ready state.

#### 9.3.2 Mode Configuration
| Mode | Signal | Value | Description |
|:---:|:---:|:---:|:---|
| Normal | `MODE[1:0]` | 2'b00 | Default RX Mode |
| AGC Test | `MODE[1:0]` | 2'b01 | AGC Loopback / Self-test |
| Programming | `MODE[1:0]` | 2'b10 | FPGA Remote Update Mode |

### 9.4 Supply Voltage, Current & Temperature Monitoring
#### 9.4.1 Supply Monitoring
*   **IC:** ADP5054.
*   **Interface:** I2C (Address 0x58).
*   **Monitored Rails:** VCCINT (0.85V), VCCAUX (1.8V), +5V_RF, +1.2V_ADC.
*   **Function:** Firmware must poll I2C every 100ms for voltage faults. Over-voltage triggers immediate shutdown of RF path (TRP disable).

#### 9.4.2 Temperature Monitoring
*   **Source:** ADP5054 internal sensor or Xilinx SYSMON (XADC) inside FPGA.
*   **Range:** -40°C to +85°C (Industrial).
*   **Action:** If Temp > +85°C, FPGA reduces ADC sampling rate or asserts alert to host via UART.

### 9.5 Flash & Interfaces
#### 9.5.1 Configuration Flash
*   **Part Number:** MT25QU01G (Assumed based on Xilinx Std, 1Gb).
*   **Interface:** Quad-SPI (x4 mode).
*   **Purpose:** Stores FPGA bitstream.
*   **Pins:** `QSPI_CS_B`, `QSPI_CLK`, `QSPI_MOSI_0/1/2_3`.

#### 9.5.2 Data Storage (Optional)
*   **Interface:** May utilize the same QSPI flash or a secondary partition to store calibration tables (Gain vs Freq).

### 9.6 LO Synthesis Control
*   **Component:** ADF5355.
*   **Interface:** SPI (Mode 0, CPOL=0, CPHA=0).
*   **Speed:** Max 10 MHz CLK.
*   **Register Map:** 14 registers (R0 to R13) via 32-bit writes.
*   **Procedure:**
    1.  Write `MUXOUT` register to enable R-Counter.
    2.  Write Frequency Registers (INT, FRAC, MOD).
    3.  Write Function Register to assert `Autocalibration`.
    4.  Wait for `MUXOUT` to indicate Digital Lock (via GPIO monitoring if implemented, or delay).
*   **Signals:** `SPI_CLK_PLL`, `SPI_MOSI_PLL`, `SPI_MISO_PLL`, `SPI_CS_PLL_N`.

### 9.7 FPGA Remote Programming
*   **Protocol:** UART at 115200 baud.
*   **Tool:** Host PC Utility.
*   **Procedure:**
    1.  Host sends "Enter Prog Mode" command (0xAA).
    2.  FPGA erases Flash sector.
    3.  Host sends bitstream packets.
    4.  FPGA writes to Flash via SPI IP.
    5.  FPGA triggers IPROG command to reload bitstream.

### 9.8 TRP / RF Control
*   **Signal:** `RF_ENABLE` (Derived from GPIO).
*   **Destination:** Controls bias to PA/LNA stages (if external T/R switch exists) or enables LTM4644 outputs.
*   **Safety:** `RF_ENABLE` is held LOW during FPGA configuration.

### 9.9 Beam Steering / Phase Control (N/A)
*   *Note: This specific iguyc hardware module is a Receiver only. It does not contain Phase Shifters or PA arrays. Therefore, Beam Steering logic is handled by an upstream system, not this FPGA glue logic.*

### 9.10 ADC Synchronization
*   **Signal:** `ADC_SYNC`.
*   **Direction:** FPGA -> ADC.
*   **Function:** Synchronizes the JESD204B Local Multi-frame Clock (LMFC) in the FPGA with the ADC Device Clock.
*   **Timing:** Must be pulsed low periodically or at startup to align lanes (Subclass 1 requirement).
