## 1. Scope of the Document
This document explains the IO details and functional requirements of the FPGA for **dkfjg**. It bridges the hardware netlist (P4) and the FPGA HDL design (P7), defining the signal interfaces, power sequencing, control protocols, and register map required to operate the 5–18 GHz RF receiver chain.

Targeted audience: Hardware Design, Firmware, and Systems Engineering teams.

## 4. Module Overview

**RF SECTION:**
The RF Front-end consists of a wideband LNA (HMC1042LP4BE) providing 24 dB gain, followed by a digitally controlled VGA (HMC698LP4) offering 0-22 dB gain adjustment in 1 dB steps. The signal passes through a Bandpass Filter (CBP-1810-LF) and is downconverted by a Mixer (HMC774A) using an LO signal generated by ADF4355. The IF signal is amplified by ADA4817 before digitization. This chain covers 5-18 GHz with high linearity (IIP3 >20 dBm).

**DIGITAL SECTION:**
The digital core is based on a Xilinx Kintex-7 FPGA (XC7K70T). The FPGA acts as the system controller, configuring the RF path via SPI/I2C (VGA gain, PLL frequency), monitoring system health via I2C (LTC2992), and managing power sequencing. It receives digitized IF data via JESD204B from the ADC12J4000 and processes it for transmission. It also handles the user interface command protocol (UART) and system status LEDs.

**POWER SUPPLY SECTION:**
Power is derived from a 12V DC input (J4). The LTM4644 DC-DC buck converter generates intermediate rails. LT3045 (5V) supplies RF components (LNA, Mixer, PLL). LT3042 (3.3V) supplies FPGA I/O and auxiliary logic. LT3033 (1.8V) supplies FPGA VCCAUX. The FPGA core voltage (1.0V) is generated by an integrated regulator on the LTM4644 or a dedicated rail.

## 5. Features
- **FPGA:** Xilinx XC7K70T-484FBG484C (Kintex-7 Family).
- **On-board clock:** 125 MHz LVDS Oscillator for FPGA system clock.
- **High-Speed Data Link:** JESD204B Subclass 1 (8 lanes) interface to ADC12J4000 @ 4 GSPS.
- **Control Interfaces:**
    - SPI Master for VGA (HMC698LP4), Synthesizer (ADF4355), and Flash.
    - I2C Master for Clock Gen (LMK04828) and Power Monitor (LTC2992).
- **Debug Interface:** JTAG (14-pin) for FPGA programming and debug.
- **RF Control:** 3-wire Serial Interface for VGA Gain control; SPI for PLL configuration.
- **Power Management:** Real-time monitoring of Voltage, Current, and Temperature via LTC2992.
- **External Comms:** UART (RS-232/422 transceiver compatible) for host control.
- **Storage:** SPI Flash (128 Mb) for FPGA configuration and Non-volatile parameter storage.

## 9. Functional Specifications

**Summary table:**

| S.No. | Function Name | Description |
|-------|--------------|-------------|
| 1 | Serial Communication Interface | UART between PC & FPGA for setup/control (via Header J5) |
| 2 | High Speed Communication Interface | JESD204B Subclass 1 (4 Lanes, 4.0 Gbps) to ADC12J4000 |
| 3 | Power Supply Sequencing & Health Status | Controls enable pins for regulators and monitors PWR_GOOD |
| 4 | Supply Voltage, Current & Temperature Monitoring | I2C-based monitoring via LTC2992 |
| 5 | Flash Interfaces | SPI Configuration Flash and Storage |
| 6 | TRP Configuration | Transmit/Receive Pulse or general RF Enable control |
| 7 | FPGA Remote Programming | Configuration loading via UART (Legacy) |
| 8 | VGA Controlling | Digital Attenuation control via 3-wire Serial and SPI |
| 9 | Beam/Frequency Tuning | ADF4355 PLL frequency setting via SPI |

### 9.1 Serial Communication Interface
- **Interface type:** UART
- **Physical layer:** TTL (Level shifted to RS-232/422 by Host)
- **Baud rate:** 3,000,000 bps (3 Mbps default)
- **Frame format:** 1 start bit, 8 data bits, 1 stop bit, no parity (8N1)
- **Connector:** Header J5 (Control Interface)
- **Signals:** UART_TX (FPGA → PC), UART_RX (PC → FPGA)
- **Protocol:** Custom register-based command/response defined in Section 11.

### 9.2 High Speed Communication Interface
- **Interface:** JESD204B Subclass 1
- **Number of lanes:** 4 (bonded mode)
- **Data rate per lane:** 4.0 Gbps (Configurable)
- **Protocol:** JESD204B
- **Physical:** AC-coupled LVDS connections to ADC12J4000.
- **Sync:** Deterministic latency using SYSREF from LMK04828.

### 9.3 Power On/Off Sequence
#### 9.3.1 Power ON/OFF Sequence
1. **Input Supply (+12V) applied:** LTM4644 (U10) enables.
2. **Rail Ramp-up:** 5V, 3.3V, 1.8V, 1.0V ramp up per PMIC requirements.
3. **Power Good Assertion:** PMIC asserts PWR_GOOD.
4. **FPGA Release:** FPGA finishes configuration (DONE = High).
5. **RF Enable:** FPGA waits for stability, then asserts TRP (RF Enable) and enables VGA EN pin.
6. **Normal Operation:** ADC Data capture begins.

#### 9.3.2 Mode Configuration
| Mode | Signal | Value | Description |
|------|--------|-------|-------------|
| Normal | MODE[1:0] | 2'b00 | Default operating mode |
| Calib | MODE[1:0] | 2'b01 | Internal calibration loop |
| Programming | MODE[1:0] | 2'b11 | Flash programming mode via UART |

### 9.4 Supply Voltage, Current & Temperature Monitoring
#### 9.4.1 Supply Voltage and Current Monitoring
- **IC Part Number:** LTC2992
- **Interface:** I2C (Address 0x6C)
- **Monitored Rails:** 12V Input, 5V RF rail, 3.3V Digital rail, 1.0V Core rail.
- **Measurement range:** 0 to 60V, 0 to 10A (via sense resistors).
- **Resolution:** 16-bit Delta-Sigma ADC.

#### 9.4.2 Temperature Monitoring
- **IC Part Number:** LTC2992 (Internal) + ADC12J4000 Internal.
- **Interface:** I2C (LTC2992), JESD204B (ADC internal temp via bits).
- **Temperature range:** -55°C to +125°C.
- **Alert threshold:** 120°C (Hardware alarm re-triggers reset if exceeded).

### 9.5 Flash & Interfaces
#### 9.5.1 Configuration Flash
- **Part Number:** S25FL128S (128 Mb)
- **Interface:** SPI (x4 Mode supported)
- **Purpose:** Stores FPGA bitstream and User calibration data.
- **Programming:** Internal FPGA Master or JTAG.

#### 9.5.2 Storage Flash (User)
- Same physical device, partitioned. Stores LUTs for Gain/Phase correction.

### 9.6 TRP Configuration
- **Signal:** TRP (General RF Enable)
- **Direction:** FPGA → RF Front-end (via J5 or dedicated trace).
- **Logic level:** 3.3V LVTTL
- **Active state:** HIGH = RF Chain Powered/Enabled.
- **Control:** Via Register `RF_CTRL` (Offset 0x04) in Register Map.

### 9.7 FPGA Remote Programming
- **Protocol:** UART (defined in Section 11).
- **Procedure:**
  1. Host sends "Enter Prog Mode" command (Special Frame).
  2. FPGA erases Flash sector.
  3. Bitstream transferred in 4KB packets.
  4. CRC verification.
  5. FPGA Soft-Reset and reload.

### 9.8 VGA Controlling
- **Interface:** 3-Wire Serial (CLK, DATA, LE) & SPI Fallback.
- **Component:** HMC698LP4.
- **Operation:**
  - **3-Wire Mode:** FPGA toggles `VGA_CLK`, shifts data on `VGA_DATA`, pulses `VGA_LE` to latch. Used for fast gain changes (6-bit gain code).
  - **SPI Mode:** Full configuration access via `SPI_CS_N` and `SPI_MOSI`.

### 9.9 Frequency Tuning (PLL)
- **Component:** ADF4355.
- **Interface:** SPI (Mode 0/1 compatible).
- **Operation:**
  1. FPGA writes 4 registers (Int, Frac, Mod, R) to ADF4355.
  2. Update bit toggles to calibrate VCO.
  3. Frequency range 5-18 GHz supported via fundamental VCO or dividers.

### 10.3 Register Access Rules
- **Addressing:** 16-bit address space.
- **Word Size:** All registers are 16-bit.
- **Read/Write:** Single and Bulk (Burst) supported via UART protocol.
- **Atomic Access:** Write to `VGA_GAIN_3WIRE` triggers an immediate hardware state machine update; no separate latch register needed for software.
- **Shadow Registers:** PLL registers are double-buffered internally by the ADF4355; write `PLL_CTRL` update bit to latch.

## 11. UART Register Protocol Specification

### 11.1 Physical Layer
- **Baud rate:** Default 3.0 Mbps (Configurable via Reg 0x0100).
- **Frame format:** 1 start bit, 8 data bits, 1 stop bit, no parity (8N1).
- **Physical interface:** 3.3V LVTTL (Level shifter required for RS-422/RS-232 connection).

### 11.2 Command Frame Formats

**Single Register Write (CMD = 0x57 'W'):**
```
Byte 0: 0x57 (CMD)
Byte 1: ADDR[15:8] (address MSB)
Byte 2: ADDR[7:0]  (address LSB)
Byte 3: DATA[15:8] (data MSB)
Byte 4: DATA[7:0]  (data LSB)
→ Response: 0x06 (ACK) within 1ms, or 0x15 (NAK) on error
Total frame: 5 bytes TX, 1 byte RX
```

**Single Register Read (CMD = 0x52 'R'):**
```
Byte 0: 0x52 (CMD)
Byte 1: (ADDR[15:8] | 0x80)  (MSB with read bit set)
Byte 2: ADDR[7:0]             (address LSB)
→ Response: DATA[15:8], DATA[7:0] within 2ms
Total frame: 3 bytes TX, 2 bytes RX
```

**Bulk Register Write (CMD = 0x42 'B'):**
```
Byte 0: 0x42 (CMD)
Byte 1: ADDR[15:8] (start address MSB)
Byte 2: ADDR[7:0]  (start address LSB)
Byte 3: N          (register count, 1–64)
Byte 4..4+2N-1: DATA[0]_H, DATA[0]_L, ..., DATA[N-1]_H, DATA[N-1]_L
→ Response: 0x06 (ACK) within 5ms, or 0x15 (NAK)
Total frame: (4 + 2N) bytes TX, 1 byte RX
```

**Bulk Register Read (CMD = 0x62 'b'):**
```
Byte 0: 0x62 (CMD)
Byte 1: (ADDR[15:8] | 0x80)  (MSB with read bit set)
Byte 2: ADDR[7:0]             (start address LSB)
Byte 3: N                     (register count, 1–64)
→ Response: DATA[0]_H, DATA[0]_L, ..., DATA[N-1]_H, DATA[N-1]_L within 5ms
Total frame: 4 bytes TX, 2N bytes RX
```

**Error Response:**
```
0x15 (NAK) — sent by FPGA when:
  - CMD byte not recognized (not 0x57, 0x52, 0x42, 0x62)
  - Address out of valid range
  - Write to read-only register
  - Parser timeout (inter-byte gap > 50ms)
```

### 11.3 Protocol Timing Constraints
| Parameter | Min | Typical | Max | Unit |
|-----------|-----|---------|-----|------|
